# Deepak Terse — Portfolio

A personal portfolio built with semantic HTML, CSS, and vanilla JavaScript. No framework, dependencies, or build step.

The simplicity is intentional. The portfolio is structured more like a story than a traditional resume, so the implementation stays close to the problem: easy to understand, fast to load, and straightforward to change.

[Live portfolio](https://deepak-terse.github.io/)


## Design principle

Choose the simplest architecture that comfortably solves the problem.

## Maintenance Notes

- **Analytics:** [Umami dashboard](https://cloud.umami.is/analytics/eu/websites/920e3d0e-b15a-49dd-9792-37248655b891?date=7day&page=1) - Sign-in using Google SSO
- **Resume:** Keep `assets/documents/deepak-terse-resume.pdf` up to date; it is linked from the portfolio.
- **Yearly:** Update the hard-coded copyright year in the footer of `index.html`.
- **Domain changes:** Keep the canonical/social URLs in `index.html` and URLs in `sitemap.xml` and `robots.txt` in sync.
