# Deepak Terse — Portfolio

[Visit the portfolio](https://deepak-terse.github.io/)

Built with semantic HTML, CSS, and vanilla JavaScript. No framework, dependencies, or build step.

The simplicity is intentional. The portfolio is structured more like a story than a traditional resume, so the implementation stays close to the problem: easy to understand, fast to load, and straightforward to change.

## Design principle

Choose the simplest architecture that comfortably solves the problem.
